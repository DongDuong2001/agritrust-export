# Security Policy

## Supported Versions

Only the latest version of AgriTrust Export is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AgriTrust Export, please do not report it via public GitHub issues. Instead, report it by contacting the maintainers directly or opening a draft security advisory on GitHub.

We will acknowledge your report within 48 hours and work with you to coordinate a security release to resolve the issue.
